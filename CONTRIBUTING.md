# Contributing to GroupMe MCP Server

Thank you for your interest in contributing! This project is an open-source Model Context Protocol (MCP) server for GroupMe, written in Go.

## Code of Conduct
Please be respectful and constructive in issues and pull requests.

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Make your changes.
4. Ensure the tests pass: `go test ./...`
5. Ensure your code is formatted: `gofmt -w .`
6. Submit a pull request.

## Development Setup
- Go 1.23+ is required.
- Clone the repository.
- Run `go build ./...` to build.
- Run `go test ./...` to test.
