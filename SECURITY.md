# Security Policy

## Supported Versions

Currently, only the latest `main` branch is supported with security updates.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Instead, please email the maintainer or send a direct message if applicable. We will review the vulnerability and work with you to release a fix.

## Security Best Practices
- **Do not expose your GroupMe tokens.**
- **Use Trusted Proxy Headers only behind a secure reverse proxy.**
- **Use Rate Limiting** to prevent abuse.
- **Review High Impact Tools** settings and restrict broad tools (e.g. `@all` mentions) if necessary.
